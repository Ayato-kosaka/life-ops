# 宿（ホステル）を調べる（Google マップ）

Chrome で Google マップを操作し、都市・日程ごとの安いホステルと価格を表にする。**調べるところまで**で、予約・決済・ログイン・個人情報の入力はしない。

## Chrome の使い方

- その環境にある Chrome の操作手段を使う（Claude in Chrome の `mcp__claude-in-chrome__*`、EC2 上の Chrome を操作するスキルなど）。
- Bot 判定や確認画面が出たら、すり抜けようとしない。人が解けるならそれを待ち、解けなければ止めて報告する。
- 表示は日本語・日本円にする（`https://www.google.com/maps?hl=ja`、通貨は設定で JPY）。

## 入力（足りなければ聞く）

| 項目 | 既定 |
|---|---|
| 都市・日程 | チェックイン日〜チェックアウト日。日程が仮なら前後1日ずらした価格も見る |
| 人数 | 1名 |
| 部屋 | 指定が無ければ最安（ドミトリーのベッド可） |

## 手順

1. Google マップで「ホステル <都市名>」を検索する。宿の一覧が出たら、日付をチェックイン・チェックアウトに、人数を1名にする。
2. **価格で絞る**: 価格の上限を下げていき、残る宿が5〜10件になるところまで絞る。一覧の価格は1泊あたりか総額かを確認して控える。
   「ホステル」で数が足りなければ、検索語を「ゲストハウス」「hostel」に変えて同じように絞る。
3. **上位の宿を開いて確認する**: 安い順に5件程度、宿の詳細を開き、次を控える。
   - 掲載先ごとの価格（Booking.com・Hostelworld・公式サイトなど）と、いちばん安い掲載先
   - 税・サービス料・都市税（現地払い）が含まれるか
   - 部屋の種類（ドミトリー何人部屋・男女混合か、個室か）
   - 評価（点数と件数）、場所（中心部・駅/バスターミナルからの距離）
   - 冬は暖房、配信・作業するなら Wi-Fi の評判が分かれば添える
4. 評価が低い（目安3.5未満）・件数が極端に少ない宿は、最安でも注記して次点を並べる。
5. 公式サイトがあれば開き、同じ日程の価格が安ければそれも書く。

## 出力

都市・日程ごとに次の表を作り、依頼元（Issue など）に貼れる Markdown で返す。

| 宿 | 部屋 | 1泊 | 総額（税込の目安） | 安い掲載先 | 評価 | 場所・メモ | 出典 |
|---|---|---:|---:|---|---|---|---|

- 表の上に**取得日時**と泊数を書く。価格は日程と残室で変わる前提で扱う。
- Google マップの宿のリンク（`maps.google.com/?cid=` など、公開された宿のページ）を出典にする。
