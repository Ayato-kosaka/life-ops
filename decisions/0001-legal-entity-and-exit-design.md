# 0001. 法人はまだ作らず日本の個人事業主で継続し、法人化は日本の株式会社で行う

- ステータス: 承認
- 決定日: 2026-08-28
- 関連: [life-ops#84](https://github.com/Ayato-kosaka/life-ops/issues/84)（検討Issue。調査の全文はIssueとAIセッションに帰属）
- 参照: `knowledge/legal/tax-position.md` / `knowledge/legal/exit-map.md` / `knowledge/platform/entity-and-payments.md`

## 決定

1. **当面は法人を作らない。** 日本の個人事業主（非居住者・納税管理人経由の申告）を継続する。
2. **Georgia LLC / Virtual Zone、Estonia OÜ、UAE法人、米国LLCは、いずれも採用しない。**
3. **法人化するときは日本の株式会社で行う。** 合同会社は選ばない。
4. **法人化のタイミングはマネタイズ開始の直前**とする。年次の節税が目的ではなく、①事業価値が個人に乗る前に法人へ移すため、②買い手が株式譲渡で買える器を用意するため。
5. **EXITを行う年の税務上の居住地はジョージアまたは香港とする。** UAE・シンガポールは選ばない。
6. 単一の外部サービス要件（Meta等）を理由に法人化を前倒ししない。

## 背景と選択肢

#84 では「Meta APIのために法人が今すぐ必要」「Georgia VZPで実効税率を下げられる」という前提で Georgia LLC + VZP を第一候補としていた。調査により両方の前提が否定され、さらに EXIT 側の構造が判明したため、結論が入れ替わった。

| 案 | 判定 | 理由 |
|---|---|---|
| Georgia LLC + VZP | 棄却 | VZP免税は「ジョージア国内で居住創業者または現地従業員が開発したソフト」に限定（歳入庁長官令№33544、2023年以降の執行）。出国後は維持不能で遡及課税リスク |
| Georgia LLC（VZPなし） | 棄却 | Stripe・Google Play販売者登録が国として非対応。不在オーナーの銀行口座凍結事例。年16〜38万円 |
| Estonia OÜ | 棄却 | 税は最適（留保0%・国外勤務給与0%・非居住者の持分売却0%）だが、買い手の9割を占める日本の事業会社が海外法人を買いにくい。かつ「日本に納税する」という現在の方針と構造的に両立しない |
| UAE法人 / 米国LLC | 棄却 | UAEは規模に対し維持費過大。米国LLCは透明体でIP保有主体にならず、非居住外国人の米国遺産税（免税枠$60k）が構造的リスク |
| **日本の株式会社（時期を待つ）** | **採用** | 買い手が普通に買える。EXIT時の居住地をジョージア/香港にすれば日本の課税も0%。現在の納税方針と整合 |
| 日本の合同会社 | 棄却 | 種類株・ストックオプションが発行できずVC投資対象外。M&Aでも株式譲渡が取りにくい。設立費用差は誤差 |

「今すぐ作らない」を選べるのは、①現在赤字で法人固定費が純損失、②事業価値がほぼゼロで個人→法人の移転がまだ無税、③居住地の見通しが未確定、の3条件が揃っているため。待機コストはゼロで、待つことで得られる情報は大きい。

## 根拠（要約）

- **EXITの税額は「法人の国」と「売却時の居住国」の組合せで決まる。** 日本法人の株を創業者が100%保有して売ると必ず「事業譲渡類似株式」に該当し、原則15.315%課税。ただし租税条約が優先し、ジョージア・香港・米国・エストニアは居住地国のみ課税＝日本0%。UAE（条約13条3項）・シンガポール（13条4項(b)）・マレーシア・タイ・条約なし国は日本が課税する。
- **ジョージアと香港は「日本0% × 現地0%」の唯一の組合せ。** ジョージアは個人の国外源泉所得が非課税、183日で居住取得可、生活費が安く滞在実績もある。
- **国外転出時課税は既に非居住者のため発動しない。** 復活するのは「日本へ帰国→居住者→10年ウィンドウ内で5年超→再出国」の場合のみ。
- **法人設立地は後から変更できない。** 日本法人を作った後に外国法人へ株式移転すると、その移転自体が事業譲渡類似の課税イベントになる。設立時点が唯一の分岐点。
- **現在の個人事業主ポジションは想定より有利。** 住民票がないため住民税ゼロ・国民健康保険ゼロ。所得127万円まで所得税ゼロ。消費税は国外事業者扱いでプラットフォーム課税・リバースチャージが働き、実質的に無関係。法人化の損益分岐点は約1,750万円（通常の約2倍）。
- **Metaは法人を要求していない。** ビジネス認証が求めるのは登記された事業体の書類であり、開業届で足りる。任意の第三者ページを読む Page Public Content Access は別のゲートで、法人化しても承認確率は上がらない。

詳細と出典は `knowledge/` 配下を参照。

## 影響と実行

- 法人設立・海外法人設立の手続きは行わない。#84 の「Georgia LLCを今すぐ作る」暫定案は破棄する。
- 日本の個人事業主としての申告を継続する。青色申告65万円控除の要件（e-Tax申告または優良な電子帳簿）を維持する。
- 事業価値が個人に蓄積する前に法人へ移せるよう、IP・ドメイン・ストアアカウント・外部契約の名義台帳を整備する。
- EXITに向けた準備（IP帰属の一元化、プライバシーポリシーの事業承継条項、ストアアカウントの移管可能性確保）は法人化を待たずに着手する。実行タスクは GitHub Issues 側で管理する。
- ジョージア出国前に、2026年分の個人申告の要否と税務居住証明書の取得可否を現地会計士に確認する。

## 再検討トリガー

- マネタイズを開始する（＝法人化の実行時期。株式会社を設立し、価値が乗る前に資産を移す）
- 事業所得が概ね1,750万円を超える（年次の税負担で法人が有利になる）
- 日本に住む意思が固まる（EXIT時の居住地設計を日本居住前提に組み直す。EXITは20.315%になるが許容範囲）
- 買い手候補が日本国外中心になる見通しが立つ（外国法人の再評価。ただし設立後の変更は課税イベントのため設立前に判断する）
- VC調達を本気で検討する（株式会社化の前倒しとDelawareフリップの要否を判断）
- 租税条約の改正、ジョージア・香港の居住者制度の変更（年1回レビュー）
