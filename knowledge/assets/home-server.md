# 常設PC（ホームサーバー）

最終更新: 2026-10-27 ／ 根拠: 2026-10-27 の診断と、20.04 → 24.04 へのアップグレード
性質: 現在有効な事実と、目標の構成。構成を変えたとき・再インストールしたときに更新する。

日本の自宅に置き、蓋を閉じたまま24時間動かすノートPC。遠隔操作で使う。

## 機材

性能の目安（2026-10-27 に測定）: EC2 の t3.xlarge（4vCPU / 16GB）程度。1スレッドの速さは今の EC2 と同程度だが、15W の省電力 CPU のため8スレッド全体でも1スレッドの約2.8倍まで。CPU クレジットの制限は無い。SSD の読み込みは約520MB/s。

| 項目 | 値 |
|---|---|
| 機種 | LG gram 15（**15Z990-HA7TJ**、2019年モデル） |
| CPU | Intel Core i7-8565U（4コア8スレッド） |
| メモリ | 16GB |
| ストレージ | SATA SSD 512GB（OS上では 477GB） |
| ファームウェア | UEFI。起動メニューは F10、BIOS 設定は F2 |
| 電池 | **寿命**（2026-10-27: 残量0%で充電されない。容量は新品の58%、充電回数736回）。日本へ送るときに外し、AC 給電だけで使う。停電時の予備電源にはならない |

## 目標の構成

| 項目 | 構成 |
|---|---|
| OS | Ubuntu 24.04 LTS デスクトップ（標準サポートは2029年4月まで） |
| ディスク | SSD 全体を Ubuntu だけで使う。`/`（312GB）と `/home`（164GB）。スワップは `/swapfile`（2GB）。**暗号化しない**（暗号化すると無人で再起動できなくなるため） |
| 遠隔操作（CLI） | Tailscale（Tailscale SSH）。鍵の有効期限は無効にする |
| デスクトップ | ふだんは Chrome Remote Desktop の仮想デスクトップ（XFCE）だけを使い、画面の前は文字のログイン画面にする。Linux 版は画面の前の画面を映せず、同じユーザーで GNOME と仮想デスクトップに同時に入れない（GDM がパスワード直後に断る）ため。画面の前で GUI が要るときだけ `desktop-switch local`、終わったら `desktop-switch remote` で切り替える。切り替えている間は Chrome Remote Desktop では繋がらない（Tailscale と Remote Control は使える） |
| 鍵束 | 使わない。誰もパスワードでログインしないので、鍵束に頼ると再起動のたびに解除を求められて止まる。Chrome は `--password-store=basic`、gh は `--insecure-storage`（ファイルに保存）。ディスクを暗号化しない方針と同じ水準の守り |
| 遠隔操作（Claude） | Claude Code Remote Control（`--chrome --permission-mode auto`）を、よく使うリポジトリごとに常駐させ（一覧はこのPCの `~/.config/home-server/rc-repos`）、claude.ai/code から操作する。ほかのリポジトリは「なんでも用」の `~/github` から、必要になったときに clone して使う |
| Chrome | Chrome Remote Desktop のデスクトップで常に起動しておく。Claude が操作する Chrome と、人が見る画面は同じ |
| 電源 | 蓋を閉じても、操作がなくてもスリープしない |
| 更新 | セキュリティ更新は自動で適用し、再起動が必要なら 04:00 に再起動する |
| 容量の上限 | journal は 500MB、snap は2リビジョンまで、Docker は週1回、未使用分を削除 |
| 入れるもの | Chrome、Chrome Remote Desktop、Tailscale、Docker |
| 入れないもの | 印刷、Bluetooth、モデム、エラー報告、メール・オフィス・ゲームなどのアプリ |

この構成は `tools/home-server/setup.sh` で作る（何度実行しても同じ結果になる）。点検の手順は `.claude/skills/home-server/`。

## 現状（2026-10-27）

- USB メモリが無かったため、クリーンインストールではなく、その場で 20.04 → 22.04 → 24.04 へアップグレードした（Ubuntu 24.04.5 LTS、カーネル 6.8）
- 旧 Windows のパーティションと起動項目は削除した。空いた領域は、ディスク上の並びのとおり、後ろ側を `/` の拡張に、前側を `/home` に使った
- 目標の構成まで設定済み（#110）。発送前の準備と、日本に届いたあとの手順は #110 にある
- ネットワークの口は Wi-Fi だけ（有線 LAN の端子が無い）。置き場所の Wi-Fi を事前に登録しておく必要がある
- 停電などで電源が切れたら、誰かが電源ボタンを押すまで起動しない（電池が無く、通電で自動起動もしない）
