# GitHub のリポジトリ置き場（常設PC）

このフォルダは、claude.ai/code の Remote Control から使う「なんでも用」の作業場所。
`gh` で権限のあるリポジトリなら、どれでもここに取ってきて作業してよい。

- 依頼されたリポジトリ（`<owner>/<name>`）を、まずホーム直下（`~/<name>`）とこのフォルダ（`./<owner>/<name>`）で探す
- どちらにも無ければ `gh repo clone <owner>/<name> <owner>/<name>` で取得する。あれば `git pull` してから使う
- 作業を始めたら、そのリポジトリの `CLAUDE.md` と `.claude/skills/` を読んで従う
  （このセッションはこのフォルダで起動しているので、リポジトリ側の設定は自動では読み込まれない）
- 使わなくなったリポジトリは、利用者に確認してから消してよい（ディスクの空きを保つ）
