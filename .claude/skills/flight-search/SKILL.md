# 航空券を調べる（Skyscanner）

Chrome で Skyscanner を操作し、指定の区間・日付の便と価格を集めて表にする。**調べるところまで**で、予約・決済・ログイン・個人情報の入力はしない。

## Chrome の使い方

- その環境にある Chrome の操作手段を使う（Claude in Chrome の `mcp__claude-in-chrome__*`、EC2 上の Chrome を操作するスキルなど）。
  ヘッドレスのブラウザやスクリプトで価格を抜き取らない（Bot 判定に掛かり、結果も信用できない）。
- 「ロボットではありません」などの確認や Bot 判定が出たら、**すり抜けようとしない**。人が画面で解けるならそれを待ち、解けなければ止めて報告する。
- 表示通貨は日本円にし、地域は日本にする（`www.skyscanner.jp`）。

## 入力（足りなければ聞く）

| 項目 | 既定 |
|---|---|
| 出発地・到着地 | 都市単位で探す（空港が複数あれば都市コード。例 `ist` はイスタンブールの両空港） |
| 日付 | 指定日の**前後2日**を含めて広めに見る。日付が仮なら月の最安カレンダーも見る |
| 人数 | 大人1名、エコノミー、片道 |
| 手荷物 | 指定が無ければ聞く。比べるのは手荷物条件をそろえた**総額** |

## 手順

1. **月の最安カレンダー**（日付が仮のとき）: `https://www.skyscanner.jp/transport/flights/<出発>/<到着>/?adultsv2=1&cabinclass=economy&rtn=0&oym=<YYMM>`
   を開き、日ごとの最安値を控える。
2. **日付ごとの検索結果**: `https://www.skyscanner.jp/transport/flights/<出発>/<到着>/<YYMMDD>/?adultsv2=1&cabinclass=economy&rtn=0&preferdirects=false`
   - 並べ替えを「最安」にする。直行便のみの絞り込みはしない（乗継のほうが安いことがある）が、乗継時間が長すぎるもの（目安6時間超・空港をまたぐもの）は注記する。
   - 上位5件程度について、航空会社・便名・出発/到着時刻・所要・乗継・価格・販売サイトを控える。
3. **販売サイトの比較**: 最安の便を開き、販売サイトの一覧（航空会社公式と旅行会社）を確認する。
   - 旅行会社の最安は、決済手数料・手荷物・座席指定が後から足されることがあるので、その旨と公式サイトの価格を並べる。
4. **航空会社の公式サイト**: 最安候補の航空会社の公式サイトで同じ便を検索し、手荷物条件をそろえた総額を確認する。
   LCC（Wizz Air・Ryanair・Pegasus・AJet など）は、運賃に含まれる手荷物（身の回り品の寸法・機内持ち込みの有無）と追加料金を控える。
5. 空港から市内への交通（所要と目安額）が分かれば添える。

## 出力

区間ごとに次の表を作り、依頼元（Issue など）に貼れる Markdown で返す。

| 日付 | 便（航空会社・便名） | 出発→到着 | 所要・乗継 | 価格（円） | 手荷物込みの総額 | 安い販売先 | 出典 |
|---|---|---|---|---:|---:|---|---|

- 価格は**取得日時**を表の上に書く（例「2026-11-08 JST 取得」）。航空券の価格は変わる前提で扱う。
- 公式サイトのほうが安い・同額なら、そちらを推奨にする。
- 見つからなかった日付・区間（運航なし・売り切れ）も「なし」と書いて残す。
